What is verified, what is still pending, and which manufacturers should include it in a pilot.

Source-verified profile

MRPeasy positions itself as cloud manufacturing software for small manufacturers and distributors up to 200 employees. Published plans reviewed for this project start at $49 per user per month, with higher tiers adding capabilities.

Why it is in the test set

  • Multi-level BOM and production-order hypothesis.
  • Routing, scheduling and traceability hypothesis.
  • Accounting and commerce integration hypothesis.
  • Per-user economics that differ from Katana and inFlow.

Required hands-on evidence

  • Bulk item import and time to first usable workflow.
  • Multi-level BOM, routing and partial completion.
  • Lot trace from raw material to finished good.
  • QuickBooks mapping and core-data export.
  • Three-year TCO for 5, 15 and 40 active users.

Provisional fit

Include MRPeasy in a pilot when manufacturing control is more important than storefront experience. Do not select it from feature claims alone; implementation effort, user count and data quality must be tested.
